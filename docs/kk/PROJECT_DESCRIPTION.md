# Жоба сипаттамасы — EcoTender AI

Caspian Hackathon 2026 · Каспий теңізінің экологиялық тендерлерінің ашықтық платформасы.

## Экологиялық мәселе

Каспий теңізі — әлемдегі ең үлкен тұйық су айдыны. Экожүйе мұнай өнімдері мен қалдықтармен ластанудан, жағалау аймақтарының тозуынан, биоресурстардың азаюынан және **экологиялық мониторингтің жеткіліксіз цифрлануынан** қысым көруде.

Жеке жүйелік тәуекел: Каспийді қорғау мен қалпына келтіруге бөлінген қаражат (мемлекеттік бюджет, гранттар, эко-тендерлер) **ашық емес** жұмсалады. Қымбат бағалар, жалғыз қатысушыдан сатып алу, бірдей мердігерлердің қайталанатын жеңістері және процедуралық аномалиялар жобалардың нақты экологиялық әсерін төмендетеді.

## Өзектілігі

Каспий теңізін сақтауға арналған қаражатты пайдаланудың ашықтығы мен тиімділігі үшін AI-платформа қажет: шығындарды мониторингтеу, сыбайлас жемқорлық тәуекелдерін анықтау, эко-жобалардың іске асырылуын бақылау.

Сатып алуларды автоматты талдаусыз бақылау органдары мен ҮЕҰ goszakup және ұқсас порталдардағы хабарландыруларды қолмен талдауға мәжбүр. Деректер бөлінген, GIS-контекст (ЕҚТА, жағалау сызығы) қаржылық жағымен сирек байланыстырылады. EcoTender AI осы алшақтықты жабады: **сатып алу + нарық + география + AI-тәуекел** бір контурда.

## Ұсынылатын шешім

**EcoTender AI** — веб-платформа (ақпараттық жүйе + AI + GIS), ол:

1. экологиялық тұрғыдан маңызды тендерлерді жинайды (fixtures / goszakup OWS v3 / Playwright);
2. бағаларды нарықтық бағдарлармен салыстырады;
3. нысандарды Каспий картасына түсіреді (PostGIS, Leaflet, ЕҚТА / NASA GIBS қабаттары);
4. өз CatBoost моделімен **Risk Score 0–100** есептейді;
5. бағалауды аудиторға LLM API немесе шаблондық fallback арқылы түсіндіреді (кілтсіз).

Формат: веб-қосымша / цифрлық платформа / AI-шешім / деректерді талдау жүйесі / GIS-сервис.

## Өнімнің негізгі функциялары

| Функция | Пайдаланушы не көреді |
|---------|------------------------|
| Эко-тендерлер каталогы | Тізім, ел/тәуекел бойынша сүзгілер, сатып алу карточкасы |
| Интерактивті карта | Тәуекел деңгейі бойынша маркерлер, Каспий/KZ bbox |
| Risk Score | 0–100 саны және band: low / medium / high / critical |
| Explain | Мәтіндік негіздеме (үкім, себептер, сенімділік) |
| Нарықтық салыстыру | Бағаның seed/market estimate-тен ауытқуы |
| GIS-қабаттар | ЕҚТА, жұмыс полигондары, NASA GIBS (demo) |
| Ingestion | goszakup парсингі, Celery/Flower, демо-фикстуралар |
| Әкімші кабинеті | LLM/парсер кілттері (at rest шифрлау), көздерді басқару |
| Auth (demo) | viewer / analyst / admin рөлдері, JWT |

## Қолданылатын технологиялар

- **Backend:** FastAPI, SQLAlchemy 2, Alembic, Celery, Redis
- **Data:** PostgreSQL 17 + PostGIS 3.5, MinIO
- **Frontend:** React 19, TypeScript, Vite, MUI, Leaflet
- **AI/ML:** CatBoost (шешім), LLM API OpenAI-compatible (түсіндіру)
- **Ingestion:** Playwright, BeautifulSoup, lxml; `SourceAdapter` адаптері
- **Infra:** Docker Compose

## Күтілетін экологиялық әсер

- Тәуекелді эко-сатып алуларды ерте анықтау → бюджеттің нақты тазалау/мониторинг/рекультивацияға жету мүмкіндігі артады.
- «Ақша ↔ аумақ» байланысы (карта + ЕҚТА) → экожүйеге зиян жоғары жерде бақылауды басым ету.
- Мемлекеттік органдар, аудиторлар және қоғам үшін ашықтық → Каспийді сақтау бағдарламаларына сенімнің өсуі.
- Каспий өңірі елдеріне көз адаптерлері арқылы масштабтау (KZ → AZ/RU/…).

*Өнім disclaimer:* Risk Score — аналитикалық сигнал, заңды айыптау емес.
