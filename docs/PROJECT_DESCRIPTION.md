# Описание проекта — EcoTender AI

Caspian Hackathon 2026 · платформа прозрачности экологических тендеров Каспийского моря.

## Экологическая проблема

Каспийское море — крупнейший замкнутый водоём мира. Экосистема испытывает давление от загрязнения нефтепродуктами и отходами, деградации прибрежных зон, сокращения биоресурсов и **недостаточной цифровизации экологического мониторинга**.

Отдельный системный риск: средства, выделяемые на охрану и восстановление Каспия (госбюджет, гранты, эко-тендеры), расходуются **непрозрачно**. Завышенные цены, закупки у единственного участника, повторные победы одних и тех же подрядчиков и процедурные аномалии снижают реальный экологический эффект проектов.

## Актуальность

Нужна AI-платформа для прозрачности и эффективности использования средств на сохранение Каспийского моря: мониторинг расходования, выявление коррупционных рисков, контроль реализации эко-проектов.

Без автоматизированного анализа закупок органы контроля и НКО вынуждены вручную разбирать объявления на goszakup и аналогах. Данные разрознены, GIS-контекст (ООПТ, береговая линия) редко связан с финансовой стороной. EcoTender AI закрывает этот разрыв: **закупка + рынок + география + AI-риск** в одном контуре.

## Предлагаемое решение

**EcoTender AI** — веб-платформа (информационная система + AI + GIS), которая:

1. собирает экологически релевантные тендеры (fixtures / goszakup OWS v3 / Playwright);
2. сопоставляет цены с рыночными ориентирами;
3. накладывает объекты на карту Каспия (PostGIS, Leaflet, слои ООПТ / NASA GIBS);
4. считает **Risk Score 0–100** собственной моделью CatBoost;
5. объясняет оценку аудитору через LLM API или шаблонный fallback (без ключа).

Формат: веб-приложение / цифровая платформа / AI-решение / система анализа данных / GIS-сервис.

## Основные функции продукта

| Функция | Что видит пользователь |
|---------|------------------------|
| Каталог эко-тендеров | Список, фильтры по стране/риску, карточка закупки |
| Интерактивная карта | Маркеры по уровню риска, bbox Каспия/KZ |
| Risk Score | Число 0–100 и band: low / medium / high / critical |
| Explain | Текстовое обоснование (вердикт, причины, уверенность) |
| Рыночное сравнение | Отклонение цены от seed/market estimate |
| GIS-слои | ООПТ, полигоны работ, NASA GIBS (demo) |
| Ingestion | Парсинг goszakup, Celery/Flower, демо-фикстуры |
| Кабинет администратора | Ключи LLM/парсеров (шифрование at rest), управление источниками |
| Auth (demo) | Роли viewer / analyst / admin, JWT |

## Применяемые технологии

- **Backend:** FastAPI, SQLAlchemy 2, Alembic, Celery, Redis
- **Data:** PostgreSQL 17 + PostGIS 3.5, MinIO
- **Frontend:** React 19, TypeScript, Vite, MUI, Leaflet
- **AI/ML:** CatBoost (решение), LLM API OpenAI-compatible (объяснение)
- **Ingestion:** Playwright, BeautifulSoup, lxml; адаптер `SourceAdapter`
- **Infra:** Docker Compose

Подробнее: [STACK.md](STACK.md), [ARCHITECTURE.md](ARCHITECTURE.md), [ML_RISK_ENGINE.md](ML_RISK_ENGINE.md).

## Ожидаемый экологический эффект

- Раннее выявление рисковых эко-закупок → больше шансов, что бюджет дойдёт до реальной очистки/мониторинга/рекультивации.
- Связка «деньги ↔ территория» (карта + ООПТ) → приоритет контроля там, где ущерб экосистеме выше.
- Прозрачность для госорганов, аудиторов и общественности → рост доверия к программам сохранения Каспия.
- Масштабирование на страны Каспийского региона через адаптеры источников (KZ → AZ/RU/…).

*Disclaimer продукта:* Risk Score — аналитический сигнал, не юридическое обвинение.
